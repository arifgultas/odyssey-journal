#### 🔴 6.1.1 — iOS Developer Build Alma (Ekran Görüntüleri İçin)
- [ ] **Öncelik:** 🔴 Zorunlu (Ekran görüntüleri için ön koşul) | **Süre:** ~30-45 dakika

**Neden Gerekli?**
Expo Go ile alınan ekran görüntüleri Store kalitesinde değildir (Expo Go banner'ı, debug overlay vb.). Gerçek uygulama deneyimini yansıtan screenshot'lar için EAS Developer Build gerekir.

5. Hem Light Mode hem Dark Mode için ayrı ayrı alın.

#### Seçenek 1: Google Workspace (Önerilen — $6/kullanıcı/ay)
- [ ] **Süre:** ~15 dakika

**Neden Öneriliyor?**

- [ ] **Süre:** ~10 dakika
