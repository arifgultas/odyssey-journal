## 2. Uygulamadan istenen: paylaşılan link uygulamada açılsın (**build 8'den önce**)

Native ayar değiştiği için Expo Go / OTA ile gelmez, build gerekir.

| | Eski (çalışmaya devam eder) | Yeni |
|---|---|---|
| EN | `https://odysseyjournal.app/?post=<id>` | `https://odysseyjournal.app/p/<id>` |
| Diğer diller | `https://odysseyjournal.app/tr/?post=<id>` | `https://odysseyjournal.app/tr/p/<id>` |

Neden yol: Android intent filtreleri sorgu parametresine bakamaz; `/`'yi sahiplenmek sitenin her açılışını
uygulamaya yönlendirirdi.

1. **`app.config.ts`**
   ```ts
   ios: { associatedDomains: ["applinks:odysseyjournal.app"], … },
   android: {
     intentFilters: [{
       action: "VIEW",
       autoVerify: true,
       data: [
         { scheme: "https", host: "odysseyjournal.app", pathPrefix: "/p/" },
         { scheme: "https", host: "odysseyjournal.app", pathPattern: "/../p/.*" }, // /tr/p/<id> …
       ],
       category: ["BROWSABLE", "DEFAULT"],
     }],
     …
   },
   ```
2. **`lib/share.ts` → `generatePostShareUrl`:** `siteUrl(\`/?post=…\`)` → `siteUrl(\`/p/${encodeURIComponent(postId)}\`)`
   (dil öneki `siteUrl`'den; EN kökte).
3. **`lib/deep-links.ts` → `mapAppLink`:** `redirectSystemPath`'e tam adres (`https://odysseyjournal.app/tr/p/<id>`)
   ya da yalnız yol (`/tr/p/<id>`) gelebilir; ikisi de `/post-detail/<id>` olmalı. Şema + ana makineyi at, isteğe
   bağlı iki harfli dil önekini atla, `p/<id>`'yi `post/<id>` gibi ele al. `odysseyjournal://post/<id>` aynen kalır.
4. **Testler:** `share` (EN ve `tr` için `/p/`), `deep-links` (`https://…/p/<id>`, `https://…/tr/p/<id>`,
   `/tr/p/<id>`, eski `odysseyjournal://post/<id>`, eşleşmeyen yol aynen döner).

**Arif'ten iki bilgi** (siteye verilecek; site doğrulama dosyalarını bunlar gelince yayınlar, o zamana kadar link
siteye düşer, bir şey bozulmaz):
- Apple **Team ID**: developer.apple.com → Membership details (10 karakter).
- Android **SHA-256**'lar: `eas credentials -p android` (production keystore) **ve** Play Console → Test ve yayınla →
  Uygulama bütünlüğü → Uygulama imzalama anahtarı sertifikası.

**Build 8 cihazdayken doğrulama:** iPhone'da Notlar'a `https://odysseyjournal.app/tr/p/<gerçek id>` → dokun →
uygulamada açılmalı. Android: `adb shell pm get-app-links com.odysseyjournal.app` → `verified`. Uygulama silinmişken
aynı link → site.
